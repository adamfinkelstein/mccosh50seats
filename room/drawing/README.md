# Architectural drawing (not in the repository)

`room/extract_seats.py` reads the seat line work from:

    A-102_from_McCosh_50_Summer_2020_Record_Drawings.pdf

Sheet **A-102.00, "Summer 2020 – Second Floor and Balcony Construction Plan"**, McCosh 50, McCosh Hall,
Princeton University (1100 Architect, P.C.; Record Set dated 2020-10-14; project 10010818).

The drawing is not included in the public repository. To re-run the extraction, obtain it from
Princeton University Facilities and save it in this directory under the file name above.
You only need it to regenerate `room/seats.csv`, which is already committed.
